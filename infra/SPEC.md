# SPEC Day 3 — InsightHub trên Kubernetes/EKS

## Mục tiêu và phạm vi

Triển khai lại InsightHub từ cùng source bằng Terraform, Helm và GitHub Actions. `web`, `api`, `ingestion-worker` chạy trên Kubernetes; PostgreSQL 16/pgvector và Redis chạy lần lượt trên RDS và ElastiCache khi kiểm chứng AWS. Upload vẫn trả `202/pending`; worker xử lý qua Redis và chat chỉ dùng tài liệu `ready`. Môi trường phải truy cập được bằng HTTPS trong lượt lab, rồi xóa tài nguyên AWS ngay sau khi lấy đủ evidence.

Đầu vào: Day 1 async năm thành phần và Day 2 MCP (ít nhất bốn backend) đã hoàn thiện; Compose chạy và smoke được, cluster Kubernetes local sẵn sàng. Chuẩn bị Helm, Terraform ≥ 1.10 (pin bản đã validate), tflint, Checkov, Conftest, Infracost, GitHub Actions và AWS sandbox cho bước cần chứng minh cloud. Thực hiện theo thứ tự Compose → Helm/Kubernetes local → AWS. PASS local không chứng minh EKS, RDS, ElastiCache hoặc OIDC đã hoạt động.

## Evidence và điều kiện hoàn thành

Nộp source/PR, prompt log và các evidence trong bảng. `evidence/day3.json` trỏ tới artifact `deployment` và `ci_binding`; binding chứa `source_sha256` của source hiện tại và `artifact_sha256` của deployment artifact. GitHub run thành công phải cung cấp artifact `verification-source/source-manifest.json` với hai hash khớp. Lưu report/binding/build archive trong `evidence/` để tránh vòng lặp fingerprint. Chạy `bash scripts/verify-day-3.sh --ci-repo owner/repo --ci-run-id NUMBER --evidence-dir evidence`; kết quả PASS chỉ xác minh policy/CI/source binding trong phạm vi verifier. Profile local là bước chuẩn bị và vẫn `INCOMPLETE` cho Day 3. Reviewer đối chiếu thêm plan, AWS, Helm/HTTPS, smoke và teardown; không kết luận hoàn thành chỉ từ verifier.

Điều kiện đạt rubric: IaC và CI/CD đều ít nhất L3 (mỗi phần ≥ 8/13). Nếu một gate lỗi, plan có destroy bất ngờ, source/artifact hash lệch hoặc AWS còn tài nguyên sau lab, ghi trạng thái chưa đạt và xử lý trước khi bàn giao. Không giữ tài nguyên tính phí giữa các buổi chỉ để duy trì live URL; lưu URL và evidence khi đang chạy, rồi teardown.
